📋 Instrucciones

✨ Características del Sistema
  • ✅ Optimizado para papel térmico 80mm
  • ✅ Generación automática de código QR
  • ✅ Conversión de números a letras
  • ✅ Diseño profesional y limpio
  • ✅ Estilos @media print optimizados
  • ✅ Compatible con impresoras POS
  • ✅ JavaScript puro (sin dependencias)
  • ✅ Fácil integración con cualquier sistema
💻 Ejemplo de Integración
// 1. Incluir la librería QRCode.js
<script src="https://cdnjs.cloudflare.com/ajax/libs/qrcodejs/1.0.0/qrcode.min.js"></script>

// 2. Incluir el archivo de impresión
<script src="assets/js/impresion-ticket.js"></script>

// 3. Llamar la función con tus datos
const misDatos = {
    numeroBoleto: '100 - 000016',
    fechaViaje: '2021-04-30',
    horaSalida: '05:00:00',
    placaBus: 'RG-2965',
    origen: 'Huacho',
    destino: 'Lima',
    asiento: '45',
    nombrePasajero: 'DANIEL PACHAS MAGALLANES',
    documentoPasajero: '45484645',
    importe: 25.00
};

imprimirTicket(misDatos);
